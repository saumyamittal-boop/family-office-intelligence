# ADR-0009: Streamlit app and small tool stack

**Date**: 2026-10-17
**Status**: accepted (page layout superseded in part by [ADR-0014](0014-app-structure-and-visual-direction.md): five pages with top navigation behind a sign-in screen)
**Deciders**: Project owner, facilitated by Claude (grill-me session, Q12 and Q20)

## Context

A solo builder with basic Python needs a fast route to an interactive dashboard and a stack that installs
cleanly on Windows. The proposal already names Streamlit. Explanations are required.

## Decision

Build one Streamlit app with four tabs: Profile, Recommendation, Risk and Liquidity, Scenarios. Explanations
are generated by rules from the optimiser's own output (binding constraints and their cost). No LLM is called.
Stack: Streamlit 1.57 or newer, pandas, numpy, scipy (SLSQP), plotly, pytest, with PyPortfolioOpt in tests only.
Pinned versions in one `requirements.txt` inside a virtual environment. No cvxpy.

## Alternatives Considered

### Alternative 1: cvxpy for the optimiser
- **Pros**: Cleaner expression of constraints.
- **Cons**: Can be awkward to install on Windows; not needed for six assets.
- **Why not**: Unnecessary risk to the setup.

### Alternative 2: LLM-written explanations
- **Pros**: Fluent text.
- **Cons**: Cost, variability, and harder to test.
- **Why not**: Rule-based text is deterministic and testable.

## Consequences

### Positive
- Small stack; deterministic and testable explanations; the demo runs offline.

### Negative
- Explanations are templated and less fluent.

### Risks
- Streamlit version drift. Mitigation: pin versions.
